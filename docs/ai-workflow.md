# AI 작업 흐름

상태: 현행 정책. 여러 단계의 작업을 조정할 때 읽는다. 모델·요금 설정이 아니라 이 저장소의 정보 탐색·검증·전달 절차를 정의한다.

## 단계와 필요한 정보

| 단계 | 읽고 확인할 내용 | 남길 결과 |
| --- | --- | --- |
| 범위 확인 | 최신 사용자 요청, 관련 AGENTS, 기존 diff, 지정된 이슈의 범위/AC | 이번 작업의 목표와 보존할 변경 |
| 조사 | 좁힌 파일·절, 필요한 현행 정책, 관련 원격 상태 | 근거와 해결할 차이 |
| 구현 | 최신 기준 브랜치, 변경할 코드/문서 | 목적에 맞는 최소 변경 |
| 검증 | 변경 범위의 AGENTS 기준 | 통과·실패·미실행 항목 |
| 전달 | 요청된 Git 절차, 최신 PR head·필수 체크 | 검토 가능한 PR 또는 병합 결과 |
| 종료 | 이슈의 현재 상태·연결, 실제 AC와 자동화 결과 | 중복 없는 최종 결과와 잔여 작업 |

진행 중 새 요청은 기존 목표의 범위·완료 기준에 반영한다. 필요한 권한은 사용자 요청에 근거하며 정책 문서만으로 외부 변경 권한을 확대하지 않는다.

## 읽기와 도구 호출 줄이기

1. root AGENTS와 작업 앱의 AGENTS를 적용하고, 상세 문서는 작업 종류가 요구할 때만 읽는다. UI면 design, 데이터 흐름이면 architecture, 비교·재현이면 baseline을 선택한다.
2. 같은 세션에서 확인한 문서는 내용이 바뀌거나 의문이 생길 때만 재확인한다. 전수 검색보다 `rg --files`와 좁힌 경로/키워드 검색을 먼저 사용한다.
3. 지정된 이슈는 바로 조회한다. 새 이슈가 필요할 때만 관련 범위에서 중복을 검색한다. 전체 backlog·전체 PR 본문·모든 과거 기록을 기본으로 가져오지 않는다.
4. 독립된 읽기/검증은 묶고, 변경과 그 결과 확인은 순서대로 수행한다. 응답은 필요한 필드만 남긴다.
5. 변하는 원격 정보는 작업 전과 쓰기·병합 직전에 확인한다. 체크/자동화 대기는 변화 시점에 맞추고, 같은 결과를 짧은 간격으로 반복 조회하지 않는다.
6. 최초 관련 검증이 통과하면 새로운 변경·실패·미해결 문제가 없는 한 반복하지 않는다. 문서도 빌드 입력인지 확인하며, Tailwind 스캔 같은 영향은 관련 생성물 비교로 좁혀 검증한다. 필요 없는 의존성 설치·전체 앱 빌드는 추가하지 않는다.
7. 원문은 소유 문서에 유지하고 PR/Linear에는 변화·검증·제한과 링크를 요약한다. 같은 결과를 본문·댓글·첨부에 반복 작성하지 않는다.

## 안전한 구현과 종료

기존 미커밋 작업과 새 작업을 섞지 않는다. 현재 checkout을 옮기기 어렵다면 최신 원격 기준의 별도 worktree를 사용한다. 새 작업 브랜치를 만든 것만으로 원격 기준 확인을 대체하지 않는다.

초안·계획·구현·검증·병합·운영 배포는 각각 사실에 맞게 기록한다. Git 이력·보안 ruleset·Linear 상태 자동화를 우회해 완료 상태만 맞추지 않는다. 저장소 변경은 실제 AC를 충족하는 PR과 병합을 확인한다.

상세 전달 절차는 [Git 운영](./git-workflow.md), 이슈 종료와 자동화는 [Linear 운영](./linear-workflow.md)을 따른다. 명명/참조는 [문서 정책](./documentation-policy.md)이 소유한다.

## PIN-31 검토에서 반영한 개선

- 항상 읽는 AGENTS는 핵심 제약과 조건별 진입점으로 정리하고 상세 Web 동작은 현행 architecture에 유지했다.
- Web의 빈 README를 실행·문서 진입점으로 채웠고 API README의 MSW 실행 설명을 바로잡았다.
- 과거 측정값을 현행 기준과 구분하고, 초안 전문을 이슈에서 현행 문서 링크로 대체한다.
- Markdown이 Tailwind 생성 CSS에 영향을 줄 수 있어 문서 작업의 검증 생략 조건에 빌드 입력 여부를 추가했다.
- PR 상태 전이는 Linear 자동화가, AC·검증 근거와 잔여 작업은 작업자가 소유한다.
- 문서의 길이·호출 중복은 확인 가능한 개선 지표다. 실제 AI 토큰·비용·시간 절감률은 측정하지 않았으므로 주장하지 않는다.
