# MOTIFIN 디자인 결정과 제품 적용

상태: PIN-52에서 2026-10-25 승인한 디자인을 2026-10-27 실제 제품 화면에 적용했다. 사용자 요청으로 디자인 검토 전용 코드·경로는 제거했다. 이 문서는 승인 결정과 현재 구현의 연결을 보존한다. 경로는 `apps/web/` 기준이다.

## 디자인의 기준

[PIN-52](https://linear.app/pin-dev/issue/PIN-52)와 Codex 대화 ‘PIN-52 작업 계획 수립’의 최종 사용자 결정을 따른다. 최초 시안은 Git 커밋 `3b7bd3f731c1fece31f3430883acaf3aecbc9374`에서 이력으로 확인할 수 있다. 과거 개발 전용 URL은 더 이상 제공하지 않는다.

- 모바일 화면은 갤럭시 S25 FE의 화면 크기·정보 밀도를 참고한다. 특정 브라우저 호환성을 보장했다는 뜻은 아니다.
- MOTIFIN Mint/Navy 테마와 제품 헤더를 공통 Innova Shell 안에 적용한다. 테마는 제품 영역으로 한정하고 하나의 `main`을 유지한다. 승인 시안과 같이 기존 시스템 글꼴을 쓰며 외부 브랜드 자산을 복제하지 않는다.
- 하단 주 탐색은 월간 리뷰 / 소비 분석 / 자금 일정 3개다. 자료 가져오기와 설정은 보조 경로다. 탐색·상세·뒤로 가기에서 월과 분석 필터를 유지한다.
- 월간 리뷰는 정보 나열보다 **이번 달의 결론 → 시작 잔액·유입·유출·남은 잔액 → 변화 근거 → 다음 확인**의 위계를 우선한다. 카드 소비와 통장 현금 이동을 혼합하지 않는다.
- 소비 분석은 규모·변화·반복/일회성·분류 확인의 관점에서 카테고리 상세·월별 추이·빈도/평균·가맹점→거래로 탐색한다. 자료가 부족한 비중·비교·반복 판단은 보류한다.
- 거래 상세는 닫을 수 있는 하단 시트다. 거래 수정·분할·원본 복원과 이력을 실제 command에 연결한다. 카테고리 삭제는 연결된 배분만 미분류로 이동하고 거래 총액과 다른 배분을 보존한다.
- 가져오기는 여러 파일 선택으로 시작하며 처음부터 여러 달의 자료를 가져올 수 있다. 별도의 분석 대상 등록·월 배정·정상 파일의 의무 검토 화면은 두지 않는다. 은행/카드 안내는 파일 선택 영역에 합친다.
- 사용자 문구에는 ‘은행·카드 자료’, ‘거래 근거’, ‘자료 구분’을 사용한다. 내부 Raw·schema·processor·revision 명칭을 고객 흐름에 노출하지 않는다.
- PDF 암호는 수동 입력을 기본으로 명시 선택 저장·재사용·변경·삭제를 제공한다. 암호를 고객 화면·URL·영구 저장소·조회 캐시에 표시하지 않는다.
- 자금 일정은 실제 기록·사용자가 등록한 계획·자료의 청구를 분리한다. 이번 회차/이후 반복 변경·건너뛰기·중단을 구분한다. 소비재 재구매 시점 예측·재고 관리는 제외한다.

## 실제 제품 코드와 화면

| 역할 | 현재 위치 |
| --- | --- |
| 테마·카드·차트·하단 탐색·시트 CSS | `src/shared/ui/motifin/motifin.css` |
| 제품 헤더·월 선택·카드·접근 가능한 시트 | `src/shared/ui/motifin/presentation.tsx` |
| 정확한 정수 금액 표시·장식용 비율 | `src/shared/ui/motifin/format.ts` |
| 공통 Shell 아래 제품 단일 main·3탭/월 문맥 | `src/app/motifin-content-layout.tsx` |
| 월간 리뷰 | `/motifin/review`, `src/pages/finance-review/` |
| 소비 분석 | `/motifin/analysis`, `src/pages/finance-analysis/` |
| 거래 상세·보정·카테고리 관리 | `/motifin/spending`, `src/pages/finance-spending/` |
| 자금 일정·날짜 필터·실제 연결 | `/motifin/schedule`, `src/pages/finance-schedule/` |
| 파일 선택·결과·예외·재시도 | `/motifin/import`, `src/pages/finance-raw/` |
| 자료/카테고리/일정 진입·선택 암호 설정 | `/motifin/security`, `src/pages/finance-security/` |

페이지는 기존 loader/action·owner/epoch Query·command를 사용한다. shared 표현 컴포넌트는 서버나 합성 어댑터를 호출하지 않는다. 표시 금액은 BigInt 기반이며 차트의 제한된 Number 변환은 장식용 좌표에만 사용한다. 알 수 없는 달을 0원으로 채우지 않고, 선택 카테고리의 평균이 null이면 전체 평균으로 대체하지 않는다.

`pnpm dev`는 실제 로컬 API, `pnpm dev:web`는 제품 동작을 검증하는 MSW 어댑터로 같은 `/motifin/*` 화면을 연다. MSW·회귀용 합성 fixture는 제품 검증에 필요하므로 유지한다. 예전 시나리오 선택 도구·합성 조회 모델/메모리 액션·개발 전용 route/controller는 제거했다.

## 시안의 가정과 실제 데이터의 차이

시안이 가정한 완전한 월간 자료·확정 반복·급여 전 부족 시점·생활비 예상/가용 금액을 실제 데이터의 확정 결과로 승격하지 않는다. 현재 read model은 카드 월 전체 coverage와 반복 구매를 확정하지 않으며 자금 일정은 등록한 계획 합계만 제공한다. 해당 예측을 실제 제공하려면 입력 범위/누락/보존 금액과 계산 계약을 별도로 구현·검증해야 한다. 디자인 적용이 이 미구현 기능이나 운영 출시의 완료를 뜻하지 않는다.

이번 검증은 합성 MSW 자료로 모바일 크기 브라우저의 디자인·탐색·실제 UI command를 확인한다. 실제 금융 파일, Neon DB, 암호 키, migration과 운영 배포는 변경하지 않는다. 최신 결과·남은 출시 조건은 PIN-54/64와 [출시 전환 기준](../../api/docs/finance-release.md)이 소유한다.
