# MOTIFIN 제품 기준

상태: PIN-55 로컬 개발 인수본, 2026-10-25. PIN-54 전체 구현을 이어갈 `feature/pin-54-cash-flow-mvp`에서 관리한다. 아래 목적·브랜드·범위는 사용자 승인 결정을 인수한 기준이다. 공통 작업·검수 전 이력 보호를 위한 로컬 checkpoint 커밋으로 보존하며 push·PR·develop 병합은 별도로 진행한다. 제품 기능 구현·보안·출시 검증 완료를 뜻하지 않는다.

## 목적과 판단 기준

Product Mission v0.1, 사용자 승인일 2026-10-24:

> 흩어진 금융 기록을 관리하고 이해하는 부담을 줄여, 사용자가 매월 적은 노력으로 소득·지출·자산의 흐름과 변화를 파악하고 이상 징후와 개선 기회를 발견하도록 돕는다.

Personal Finance 제품의 사용자 노출 이름은 **MOTIFIN(모티핀)**이다. Cash Flow를 먼저 출시하고 Investments·다른 자산 관리는 후속 단계로 검토한다. 제품 목적이 첫 출시의 자산·투자 기능 전체를 승인하는 것은 아니다.

새 기능은 월간 관리 부담 감소, 금융 흐름·변화 이해, 근거 있는 발견 중 어느 기준에 기여하는지와 검증할 사용자 여정을 해당 이슈/PR에 적는다. 모든 기능이 세 기준을 동시에 충족할 필요는 없다. 기존 Sheets/ChatGPT의 투자 근거·리뷰는 보존하며, 추가 가치와 반복 갱신 부담은 별도 사용자 검증으로 판단한다.

목적 승인·수정 이력의 임시 원본은 [PIN-16](https://linear.app/pin-dev/issue/PIN-16)이다. 이 문서가 develop에 병합된 뒤 PIN-16에 해당 commit 링크를 연결하고 저장소 문서로 최신 목적 원문을 이전한다. 현재는 병합된 단일 기준으로 표시하지 않는다. 목적 변경 시 근거·날짜와 영향받는 범위/이슈를 함께 갱신한다.

## 현재 Cash Flow 범위

- 은행 상세 관리는 **월급·소비 통장 1개**다. 이 통장은 KB Pay 카드대금의 실제 결제계좌다. 은행 입출금·잔액과 카드 이용·청구·할부는 독립된 사실로 보존하며 카드대금 출금을 소비에 다시 합산하지 않는다.
- 다른 계좌는 본 통장에서 관측한 송금·수취만 표시한다. 상대 계좌 잔액·이후 운용·전체 자산·투자 여력을 추정하지 않는다. 이전의 세 통장 동시 수집·투자 평가 필수 초안은 적용하지 않는다.
- 기본 분석은 달력 월, 주 이용 흐름은 모바일 **월 1회 리뷰**다. 가져오기는 임의 시점·여러 달·다중 파일을 지원하는 방향이며 정상 자료는 자동 반영하고 문제 항목만 확인한다. 월·파일 유형을 고객이 사전 분류하도록 강제하지 않는다.
- 은행 PDF의 암호는 실행 중 직접 입력하는 경로가 기본이다. 선택 저장·재사용은 독립 기능이며 기본 가져오기의 선행 조건이 아니다.
- 월간 리뷰는 결론 → 자금 흐름 → 달라진 이유 → 다음 확인을 연결한다. 주요 탐색은 월간 리뷰 / 소비 분석 / 자금 일정이며 가져오기·설정은 보조 진입이다. 소비 근거·분류·보정·금액 분할과 실제/예정의 구분은 승인된 UX를 따른다.
- 자료 누락·카드 청구 지연·전월 없음·미확인 값은 0이나 전체 분석 완료로 표현하지 않는다. 근거가 부족하면 전체 소비·비중·월 비교와 관련 전망을 보류한다. 고객 표현은 ‘눈여겨볼 변화’, ‘확인할 항목’처럼 중립적으로 사용한다.

Investments, 타계좌 상세·예적금·전체 순자산, 금융기관 실시간 연동, 카드 실적/혜택 최적화, 소비재 재구매 예측, 고급 AI 예측은 첫 출시 범위 밖이다.

## 브랜드와 UX 참조

승인한 방향은 Signal Mint `#31E6B8`, Deep Navy `#0D1730`, Light BG `#F4F8F8`, 라이트 텍스트 강조 `#006B56`, White Surface `#FFFFFF`, Pretendard Variable이다. 모바일 가독성과 기존 공통 Shell·접근성 기준을 함께 적용한다. 기존 데스크톱 몰입 연출을 첫 MVP 필수로 두지 않는다.

이름·색상 방향의 계승과 원본 로고·폰트 파일·코드의 복제 권한은 별개다. 실제 자산 활용·출시 전 [PIN-32](https://linear.app/pin-dev/issue/PIN-32)의 권한 확인 경계를 따른다. 이 인수본은 원본 자산의 복제·반출을 승인하지 않는다.

시안 기준 커밋은 `3b7bd3f731c1fece31f3430883acaf3aecbc9374`다. 2026-10-27 디자인을 실제 제품 페이지와 `shared/ui/motifin`에 적용한 뒤 사용자 요청으로 시안 전용 route·합성 어댑터/조회 모델·메모리 액션·컨트롤러·검토 도구를 제거했다. 승인 결정과 현행 코드 매핑은 [디자인 결정·제품 적용](motifin-wireframe.md)을 따른다. 실제 금융 계산·완전성·비교 가능성은 서버 계약을 유지하며 운영 출시는 별도다.

실제 파일 형식은 확장자만으로 정하지 않는다. PIN-39에서 판독한 카드 표본은 ZIP/OOXML XLSX이며 모든 XLS 형식 지원을 입증하지 않는다. 교차 문서의 날짜+금액 일치만으로 고유 거래를 확정하지 않고 모호하면 확인 대상으로 남긴다. 구현 및 출시 검증은 PIN-56~64가 각각 소유하며 상세 설계를 먼저 전면 재작성하지 않는다.

현재 로컬 Cash Flow 구현의 실제 가져오기·리뷰·분류·분석·일정·선택 암호 경로와 출시 잔여 조건은 [출시 검증·운영 전환](../../api/docs/finance-release.md) 및 PIN-64/54를 따른다. 합성 검증 통과와 실제 Android 사용자 인수·운영 출시는 구분한다.
